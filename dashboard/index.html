New site

Downloads the latest WordPress into sites\, creates its database and wp-config.php, and serves it on the next free port. MySQL must be running.

Set up the stack

Downloads the missing parts into the stack folder. Parts already installed are kept.

Stop the stack?

Backing up dumps every site's database to its sql folder before MySQL shuts down.

Delete ?

Permanently removes the site's files, its database and its Nginx config. This can't be undone.
